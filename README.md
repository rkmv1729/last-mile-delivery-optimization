# Data and Dependencies

This repository does **not** include the datasets, trained models, or installed Python packages used during development due to their large size and licensing restrictions.

## Data Sources

### 1. LaDe Dataset
The primary dataset used for delivery order simulation, demand analysis, and operational zone generation.

**Source:**
- https://github.com/tsinghua-fib-lab/LaDe

**Purpose:**
- Demand analysis
- Adaptive H3 Spatial Indexing (AHSI)
- Demand forecasting
- Dispatch optimization
- Simulation engine

---

### 2. Corporación Favorita Grocery Sales Forecasting

Retail sales dataset used for demand profile extraction and store-demand similarity analysis.

**Source:**
- https://www.kaggle.com/competitions/favorita-grocery-sales-forecasting

**Purpose:**
- Retail demand profiles
- Product transfer layer
- Demand similarity modelling

---

## Data Directory Structure

```
data/
├── raw/                # Original downloaded datasets
├── processed/          # Cleaned and feature-engineered datasets
├── intermediate/       # Temporary processing outputs
└── external/           # Optional external resources
```

The datasets are intentionally excluded from version control using `.gitignore`.

---

## Models

Pre-trained models are also excluded.

Typical contents include:

```
models/
├── demand_forecast_model.pth
├── demand_scaler.pkl
└── metadata.json
```

These files can be regenerated by running the corresponding training scripts.

---

## Python Environment

A virtual environment is recommended.

Create one:

```bash
python3 -m venv venv
```

Activate:

Linux/macOS

```bash
source venv/bin/activate
```

Windows

```bash
venv\Scripts\activate
```

---

## Install Dependencies

Install all required packages using:

```bash
pip install -r requirements.txt
```

The virtual environment (`venv/`) is excluded from this repository.

---

## Notes

The following are intentionally **not included**:

- Raw datasets
- Processed datasets
- Intermediate files
- Trained models
- Python virtual environments
- Cache files
- IDE configuration
- Large generated artifacts

This keeps the repository lightweight and reproducible.
